# FNF: Psych Engine 0.6.3 Mobile — v0.6.3

Android and iOS port of Psych Engine 0.6.3.

## Downloads

| Platform | File |
| --- | --- |
| Android (ARM64) | `PsychEngine063-v0.6.3-Android.apk` |
| iOS (unsigned) | `PsychEngine063-v0.6.3-iOS.ipa` |

The iOS build is not signed. Install it with a sideloading tool such as AltStore, SideStore or TrollStore.

## Features

- Touch controls on every menu: tap to select, tap again to confirm, drag to scroll and swipe to change options.
- Back button on the menus and pause button in songs.
- Two hitbox modes: **Four Lanes** and **Arrows**.
- Haptics for menus, notes, sustains and some stage events.
- Lua scripts and `runHaxeCode` support.
- Mods support, loaded from the game folder.
- Videos played with hxvlc.

## Mobile Options

Open **Options** and tap the gear in the top right corner.

| Option | Description |
| --- | --- |
| Hitbox Mode | Four Lanes or Arrows |
| Invisible Hitbox | Hides the hitbox, it still works |
| Invisible Pause Button | Hides the pause button, it still works |
| Chart Editor in Pause | Adds a Chart Editor option to the pause menu |
| Haptics | Turns vibration on or off |
| Haptics Type | All or Notes only |
| Haptics Intensity | From 0.0 to 5.0 |
| Screen Style | Original (16:9) or Full (whole screen without stretching) |
| Storage Type | Android only: Data, External, Media or Obb |

## Game folder

| Platform | Folder |
| --- | --- |
| Android (Data) | `Android/data/com.shadowmario.psychengine063/files` |
| Android (External) | `/storage/emulated/0/.PsychEngine063` |
| Android (Media) | `Android/media/com.shadowmario.psychengine063` |
| Android (Obb) | `Android/obb/com.shadowmario.psychengine063` |
| iOS | The app folder in the Files app |

Put your mods inside the `mods` folder. The Storage Type change applies after restarting the game.

## Requirements

- Android 5.0 or newer, ARM64 device.
- iOS 12 or newer.

## Built with

- Haxe 4.3.7
- HaxeFlixel 6, Lime, OpenFL
